# USLOG Casino 名簿

カジノワールドのオーナー・ディーラー・出入り禁止の名簿です。GitHub Pages で公開し、ワールドが入室時と10分ごとに読みます。
`*.github.io` は VRChat の信頼済みドメインなので、プレイヤーは設定を変えなくても読めます。

- 名簿: `https://BreakingDawn252.github.io/uslog-casino-roles/roles.json`
- 作成ツール: `https://BreakingDawn252.github.io/uslog-casino-roles/`

## 名簿の更新手順

1. 作成ツールを開き、Owners / Dealers / Banned に表示名を1行に1人ずつ入れる。
2. 「roles.json を作る」→「コピー」。
3. このリポジトリの `roles.json` を GitHub 上で開き、鉛筆アイコンで編集して貼り付け、Commit する。
4. 数分で公開され、ワールドには入室時か最大10分後に反映される。

名簿には表示名そのものではなく、`SHA-256(salt + "|" + 表示名)` だけが載ります。
ツールは入力した名前をどこにも送信しません。

## 注意

- **書き込み権限が権限そのもの**です。このリポジトリに書き込める人は自分をオーナーにできます。コラボレーターは最小限にし、全員二段階認証を有効にしてください。
- 表示名で判定するので、スタッフが表示名を変えたら名簿も作り直してください。
- 反映に数分かかります。緊急時はワールドの予備リスト(Unity のインスペクタ)と Banned で対処します。
- `salt` を変えたら、ワールド側の設定と名簿を必ず両方そろえてください(名簿に salt が書いてあれば、ワールドはそれを使います)。
